Waypoint

隐私政策

最后更新：2026 年 10 月 31 日

Waypoint 是一个个人用的 Android 应用。本页说明它处理哪些数据、数据去了哪里，以及它绝不会做什么。

简单来说

  • 你的数据存在你的手机上。
  • 没有 Waypoint 服务器，不用注册账号，没有广告，没有统计分析。
  • 数据只会因为你自己打开的三项功能离开手机：DeepSeek、Google Drive 备份和 GitHub 同步。
  • 我们绝不出售或分享你的数据。

手机上存了什么

你的目标、记录、计时、睡眠、收支记录、复盘和设置。它们存在应用的私有存储里，由 Android 加密。你分享进来的截图，在保存或丢弃那条记录后就会删除。

你的 DeepSeek API key 和 GitHub token 用 Android Keystore 里的密钥加密。它们不会进入备份，输入之后也不会再完整显示。

DeepSeek

如果你添加了自己的 DeepSeek API key，应用会把你提交的内容发给 DeepSeek 来识别和回复：你输入的文字、你分享的截图，以及相关目标的简短摘要。应用用你的 key 直接连接 DeepSeek，DeepSeek 如何处理这些数据由它自己的隐私政策约束。用快捷方式记的钱（+350、-42.50 午饭、=4210）不经过 DeepSeek。复盘只发送金额汇总，比如余额和变化。用文字描述的钱和其他文字一样会被发送。

没有 key 时，不会向 DeepSeek 发送任何内容。

Google Drive 备份

如果你打开备份，应用只向 Google 申请一项权限：drive.appdata。它只能在你 Google Drive 的隐藏应用文件夹里创建、读取和删除自己的文件，看不到你 Drive 里的其他文件。

上传前，备份会在手机上用只有你知道的密码加密（AES-256-GCM，密钥由 PBKDF2 派生）。没有这个密码，谁都读不了，包括我们和 Google。应用只用这项权限来存储、列出、恢复和清理你自己的备份。

Waypoint 对从 Google API 获得的信息的使用和传输遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

GitHub

如果你添加了只读 GitHub token，应用会读取你关联到项目类目标的仓库的 commit 信息，不会读取你的代码。如果你也添加了 DeepSeek key，commit 信息可能会由 DeepSeek 总结。

删除你的数据

卸载应用会删除手机上的所有数据。要删除备份，请在网页版 Google Drive 打开 设置 → 管理应用，找到 Waypoint，选择“删除隐藏的应用数据”。你也可以在 myaccount.google.com/permissions 移除应用的访问权限。

儿童

Waypoint 不面向 13 岁以下的儿童。

变更

如果本政策有变化，新版本会发布在本页，并更新日期。
